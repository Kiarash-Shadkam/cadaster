# سامانه جامع کاداستر، پرونده‌بندی هوشمند و مستشار قضایی (Cadaster Intelligence System)

این پروژه یک وب‌اپلیکیشن پیشرفته برای مدیریت پرونده‌های حقوقی، کیفری، تجاری و ملکی با قابلیت‌های زیر است:

- **دریافت و اسکن دسته‌ای اسناد (Unified Dossier Ingestion)**: بارگذاری همزمان فایل‌ها با انتساب قطعی به یک پرونده مشخص.
- **نام‌گذاری پیش‌فرض هوشمند**: ثبت خودکار نام فایل کاربر به عنوان عنوان پیش‌فرض هر سند با امکان ویرایش.
- **تشخیص انواع ادله و مدارک**: تفکیک رسیدهای بانکی، فیش واریز، چک صیادی، سفته، فاکتورها، قراردادها، دادنامه‌ها، لوایح و استشهادیه‌ها.
- **مدیریت کامل پرونده‌ها و اسناد در آرشیو**: ویرایش، تغییر نام، حذف امن و ادغام دسته‌ای اسناد پراکنده.
- **ستاره‌گذاری و اولویت‌بندی اسناد مهم**: با قابلیت مرتب‌سازی خودکار اسناد ستاره‌دار در صدر فهرست و فیلتر سریع.
- **سامانه حذف خودکار فایل‌های تکراری**: پالایش فایل‌های تکراری حین بارگذاری و پاکسازی یک‌کلیکی در آرشیو.
- **مستشار و دستیار ارشد حقوقی (Legal Chatbot)**: تحلیل موشکافانه پرونده‌ها با تکیه بر موازین قانونی و رویه قضایی.
- **نقشه کاداستر و درخت پرونده‌ها**: تفکیک پلاک‌های ثبتی، اراضی و پرونده‌های قضایی.

## اجرای پروژه به صورت محلی (Local Development)

```bash
# ۱. نصب وابستگی‌ها
npm install

# ۲. اجرای سرور توسعه
npm run dev

# ۳. بیلد پروژه برای پروداکشن
npm run build
```

## استقرار خودکار روی GitHub Pages (Deployment via GitHub Actions)

این مخزن به اکشن گیت‌هاب مجهز شده است (`.github/workflows/deploy.yml`). 
به محض ارسال تغییرات به شاخه `main`، پروژه به صورت خودکار بیلد شده و روی GitHub Pages دیپلوی می‌شود.

### مراحل فعال‌سازی در گیت‌هاب:
۱. به بخش **Settings** مخزن در گیت‌هاب بروید:
   `https://github.com/alireza7906/cadaster/settings/pages`
۲. در بخش **Build and deployment**، گزینه **Source** را روی **GitHub Actions** تنظیم نمایید.
۳. آدرس نهایی سایت:
   `https://alireza7906.github.io/cadaster/`
